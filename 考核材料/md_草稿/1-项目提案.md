# 项目提案 / 商业计划书

> 项目：表格数据 + LLM 融合的企业智能分析 Agent（选题 44）

## 1. 项目目标

构建一个**让业务人员用自然语言做数据分析**的智能 Agent 产品：上传 Excel/CSV，直接提问（"各区域销售额环比及异常原因"），系统自动完成结构理解→计划→代码执行（沙箱）→图表→结论，并支持追问、假设检验、留痕可复现、报告导出（docx/pdf），以及企业级安全（字段级权限、敏感列脱敏、审计）。

## 2. 预期成果

- **可运行 Web 系统 v1.0**：前端（React+ECharts）+ 后端（FastAPI+LangGraph+DuckDB）+ 真实大模型（DeepSeek）。
- **演示数据集**：多表关联示例（订单 × 负责人）等。
- **完整考核文档**：需求/设计/测试/部署等全套考核材料。
- **实现选题验收指标**：端到端正确率≥85%、代码一次通过率≥70%（反思后≥90%）、百万行查询<3s、沙箱逃逸拦截100%。

## 3. 市场分析

### 3.1 目标用户
- **业务人员**（产品/运营/销售）：不懂 SQL，需要自助取数；
- **数据分析师**：快速探索、假设验证、复用分析；
- **企业管理员**：数据权限、敏感信息合规、审计。

### 3.2 市场价值
"ChatBI / 表格 Agent"是 2026 年企业 AI 落地最快的形态之一。传统 BI（Tableau/Power BI）学习成本高、交互固定；通用大模型缺少可信与可控的执行结果。本项目以"LLM 出意图 + 沙箱真实计算 + 过程留痕"解决可信与安全两块痛点，契合 B 端热门赛道。

### 3.3 差异化
| 对比项 | 传统 BI | 通用 LLM | 本项目 |
|:---|:---|:---|:---|
| 交互 | 拖拽建模 | 自由但不可信 | 自然语言 + 可信执行 |
| 结果可信 | 高 | 低（易幻觉） | 高（沙箱真实计算） |
| 安全合规 | 中 | 弱 | 强（权限/脱敏/审计） |

## 4. 预期成本

| 成本项 | 估算 | 说明 |
|:---|:---|:---|
| 大模型 API（DeepSeek） | 少量/次 | 问答计费，演示成本低 |
| 开发环境 | 0（本机） | Python + Node 开源 |
| 存储 | 0（本机 SQLite） | 云端部署可选对象存储 |
| 人力 | 6 人 × 4 周 | 课程项目 |

## 5. 预期收益
- **课程收益**：完整掌握 LLM Agent、RAG/表格语义、沙箱安全、REST API、全栈开发与工程文档。
- **商业价值**：形成可二次开发的 ChatBI 底座，面向企业数据分析岗位的落地能力。
- **就业面向**：数据分析、BI 工程、AI 应用开发。

## 6. 风险评估
LLM 生成 SQL/代码可靠性、沙箱安全、百万行性能、API 稳定性；应对见《项目计划》风险管理表。

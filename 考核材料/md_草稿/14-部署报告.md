# 部署报告（Deployment Report）

> 项目：表格数据 + LLM 融合的企业智能分析 Agent
> 编写：成员F · 版本 v1.0

## 1. 部署环境
- 操作系统：Windows
- Python 3.13（uv 虚拟环境）；Node 22
- 后端：uvicorn + FastAPI（端口 8000）
- 前端：React + Vite（开发 5173 / 构建 dist）

## 2. 部署活动记录
| 步骤 | 操作 | 结果 |
|:---|:---|:--:|
| 1 | `uv pip install -r requirements.txt` | 成功 |
| 2 | 配置 `.env`（LLM_PROVIDER=api + Key） | 成功 |
| 3 | `npm install && npm run build` | 成功 |
| 4 | 启动后端 `uv run uvicorn app.main:app --port 8000` | 成功 |
| 5 | 启动前端 `npm run dev`（5173） | 成功 |
| 6 | 联通性 `GET /api/health` → alive | 成功 |

## 3. 系统验证结果
- 前后端启动正常，无阻塞日志；
- 上传→分析→追问→导出→审计全链路可用；
- 演示数据 `data/demo_data/` 就绪。

## 4. 遇到问题与解决
- DuckDB 读取中文路径 CSV 失败 → 回退 pandas（已内置兜底）；
- 报告中文文件名 HTTP 头编码异常 → RFC5987（已修复）。

## 5. 结论
系统已在演示环境成功部署并验证，满足交付演示要求。

# 用户验收测试计划（User Acceptance Test Plan）

> 项目：表格数据 + LLM 融合的企业智能分析 Agent
> 编写：成员F · 版本 v1.0

## 1. 目的
由用户/干系人在真实场景验证系统是否满足需求，确认可验收。

## 2. 验收用户角色
- 业务人员：验证自然语言问答、图表、结论、导出；
- 管理员：验证审计、权限/脱敏（接入后）。

## 3. 验收场景与步骤

| 编号 | 场景 | 步骤 | 期望 |
|:--:|:---|:---|:---|
| UAT1 | 上传并分析 | 上传 orders_demo.csv → 问"各区域销售额" | 出图表+结论 |
| UAT2 | 多表关联 | 上传订单+负责人 → 问"完成率" | 关联出结果 |
| UAT3 | 追问 | 问"剔除华东区域会怎样" | 返回真实重算 |
| UAT4 | 导出 | 点导出 Word/PDF | 下载含图表的文件 |
| UAT5 | 审计 | 打开审计日志新窗口 | 分页查看记录 |
| UAT6 | 概述不出图 | 问"几行几列" | 不出图 |

## 4. 通过标准
所有 UAT 场景成功且无阻断性缺陷；验收指标达标。

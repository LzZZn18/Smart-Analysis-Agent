# 小组心得体会

> 项目：表格数据 + LLM 融合的企业智能分析 Agent
> 全体成员 · 版本 v1.0

## 一、项目整体感受
在 4 周实训中，我们从零搭建了一个"上传表格 + 自然语言问答 → 自动分析 → 图表与结论 → 追问/报告导出 → 审计留痕"的完整 Agent 产品。过程中最大的收获是理解了"让大模型既聪明又可信"的工程方法。

## 二、关键技术难点与解决
1. **真实执行而非脑补**：我们把"LLM 生成代码 + 沙箱真实执行"作为可信基石，追问改为基于上轮代码重跑，从根上避免数据编造。
2. **极简追问补全**：像"一月呢"这种省略句，通过结合上轮上下文补全为完整问题，解决了歧义。
3. **沙箱安全**：深刻认识到"允许 LLM 写代码"的风险，学会用子进程隔离+白名单+超时强杀来兜底。
4. **报告可复现**：把代码、结果、真实图表一起放进 docx/pdf，是产品可信交付的关键。

## 三、团队协作
6 人按 架构/后端/算法/测试 分工，职责不重叠；每周评审问题并及时整改（见专家评审记录）。协作沟通顺畅，进度达成全部里程碑。

## 四、经验教训
- 尽早接入真实数据与模型，避免"假数据运行"掩盖问题；
- Windows 中文路径、编码等环境坑要提前规避；
- 文档与代码同步写，为考核与答辩做准备。

## 五、展望
后续可补敏感列脱敏、字段级权限、沙箱真限额、Docker 部署与量化评测，进一步做成可交付给企业使用的 ChatBI 底座。

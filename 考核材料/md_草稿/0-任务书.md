## 二、项目背景与目标

企业数据分析正被 AI 重塑。本项目构建一个"表格数据 + LLM 融合"的智能分析 Agent：
用户上传本地表格（Excel/CSV，支持多表关联、百万行级），用自然语言提问，Agent 自动完成
**表格结构理解 → 分析计划 → 生成并执行代码（沙箱）→ 图表生成 → 结论撰写** 的闭环，
并支持追问与假设检验、分析留痕可复现、报告一键导出（docx/pdf），企业版能力含字段级权限与敏感列脱敏。

**目标**：交付一套可运行的 Web 应用系统 + 完整考核文档 + 演示数据集，并达到选题验收指标：
端到端正确率 ≥85%、代码一次通过率 ≥70%（反思后 ≥90%）、百万行查询响应 <3 秒、沙箱逃逸拦截率 100%。

## 三、主要任务

1. 表格语义理解（Schema 画像）：列类型、示例值、空值率、基数、关联键推断。
2. 分析 Agent 闭环：计划 → 代码生成（DuckDB/pandas）→ 沙箱执行 → 失败自我修正（≤3轮）→ 结论。
3. 图表自动选型 + 结论撰写；报告导出 docx/pdf，图表可溯源。
4. 多轮追问与假设检验（what-if）。
5. 企业安全：字段级权限、敏感列脱敏、全链路审计留痕。
6. 技术选型：LangGraph + DuckDB + DeepSeek/Qwen API + ECharts；Python + TypeScript。

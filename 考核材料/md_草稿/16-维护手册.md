# 维护手册（Maintenance Manual）

> 项目：表格数据 + LLM 融合的企业智能分析 Agent
> 编写：成员F · 版本 v1.0

## 1. 常见问题与解决（FAQ）

| 问题 | 原因 | 解决 |
|:---|:---|:---|
| 分析返回"未配置 Key" | `.env` 缺 LLM_API_KEY 或为占位 | `backend/.env` 填入有效 DeepSeek Key |
| 前端连不上后端 | 后端未启动/端口占用 | 启动 `uv run uvicorn ... --port 8000`；确认 5173 proxy 指向 8000 |
| 上传含中文路径 CSV 失败 | DuckDB 读取中文路径 | 已内置回退 pandas，或改用 ASCII 目录 |
| 报告导出报错 | 后端 500 | 检查 `data/agent.db` 可写、matplotlib 可用 |
| 追问数值异常大 | 复杂 what-if 文本推断局限 | 简化为"基于上轮代码重跑"场景 |
| 上传的表格刷新后没了 | 会话/列表恢复依赖后端 `GET /api/tables` | 确认后端运行，重启后列表自动恢复 |

## 2. 日常维护
- 备份：`data/` 目录（agent.db + 上传文件）；
- 清理：`data/` 下上传副本与 `.cache/` 可定期清理；
- 依赖更新：`uv pip sync requirements.txt`、`npm update`。

## 3. 配置维护
`.env`：`LLM_PROVIDER`（api/mock/ollama）、`LLM_API_BASE`、`LLM_API_KEY`、`LLM_MODEL`、`OLLAMA_BASE_URL`、`SANDBOX_*` 限额。修改后重启后端生效。

## 4. 升级指南
按"技术栈规范 + 提交规范"新增模块；保持中文注释；接口新增先在 `schemas`/`api` 注册并写接口设计说明。

## 5. 故障排查流程
1. 看后端进程日志（uvicorn 输出）；
2. 查 `data/agent.db` 数据是否正常；
3. 用 `/api/health` 探活；
4. 按 FAQ 逐项定位。

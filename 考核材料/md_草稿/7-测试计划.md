# 测试计划（Test Plan）

> 项目：表格数据 + LLM 融合的企业智能分析 Agent
> 编写：成员F · 版本 v1.0

## 1. 测试目标
验证系统功能正确性、分析结果可信性、沙箱安全、性能与报告可复现性。

## 2. 测试环境
- 后端：Python 3.13 + FastAPI，uv 管理虚拟环境；
- 前端：Node 22 + Vite（dev 端口 5173，proxy 到 8000）；
- 真实 LLM：DeepSeek API（`backend/.env` 配置 Key）。

## 3. 测试策略
| 层级 | 范围 | 方法 |
|:---|:---|:---|
| 单元 | services 各模块（画像/选型/报告/沙箱） | pytest / 脚本 |
| 接口 | REST API（上传/问答/追问/导出/审计） | requests / urllib |
| 端到端 | 前端→后端→LLM→沙箱全链路 | 模拟用户提问 |
| 性能 | 百万行 CSV | 构造 CSV 压测 |
| 安全 | 沙箱逃逸 | 恶意代码用例 |

## 4. 测试用例（部分）

| 编号 | 用例 | 预期 | 方式 |
|:--:|:---|:---|:---|
| T01 | 上传 CSV | 返回 table_id、行列数 | 接口 |
| T02 | 上传 Excel | 支持 .xlsx | 接口 |
| T03 | 问"各区域销售额" | 返回真实聚合 output + 柱状图 | 端到端 |
| T04 | 极简追问"一月呢" | 补全并重跑，返回真实 1 月数据 | 端到端 |
| T05 | 剔除华东重算 | 返回华南/华北真实值 | 端到端 |
| T06 | 导出 docx/pdf | 含数据表+真实图表图片 | 导出 |
| T07 | 审计分页+关键字 | 按操作/问题过滤 | 接口 |
| T08 | 沙箱危险 import | 拦截 os/subprocess | 安全 |
| T09 | 沙箱超时 | 超时强杀 | 安全 |
| T10 | 单行概述 | 不出图 | 功能 |

## 5. 预期验收指标
端到端正确率≥85%；代码一次通过率≥70%（反思后≥90%）；百万行查询<3s；沙箱逃逸拦截100%；报告溯源率100%。

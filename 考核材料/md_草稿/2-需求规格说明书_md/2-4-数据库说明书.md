# 数据库说明书

> 项目：表格数据 + LLM 融合的企业智能分析 Agent
> 版本：v1.0 · 编写：成员B

## 1. 概述
系统使用 **SQLite**（`data/agent.db`）存储运行时数据：已上传表格元信息（含画像缓存）、审计日志、分析结果（供报告导出与多轮轮次展示）。数据库随应用启动自动创建表结构（`init_db()`），并使用 `ALTER TABLE` 做兼容迁移（如新增 action、profile_json 列）。

## 2. 表结构设计

### 2.1 tables（已上传表格）
| 字段 | 类型 | 说明 |
|:---|:---|:---|
| table_id | TEXT PK | 唯一表标识（uuid 前 12 位） |
| filename | TEXT | 原始文件名 |
| stored_path | TEXT | 数据文件存储路径 |
| row_count | INTEGER | 行数 |
| profile_json | TEXT | Schema 画像缓存（JSON） |
| created_at | TEXT | 创建时间 |

### 2.2 audit_log（审计日志）
| 字段 | 类型 | 说明 |
|:---|:---|:---|
| trace_id | TEXT PK | 唯一流水号（关联一次操作） |
| user_name | TEXT | 操作用户（默认 anonymous） |
| action | TEXT | ask / followup / export |
| question | TEXT | 用户问题 |
| code | TEXT | 生成并执行的代码（可复现） |
| created_at | TEXT | 时间 |

### 2.3 analysis_results（分析结果）
| 字段 | 类型 | 说明 |
|:---|:---|:---|
| report_id | TEXT PK | 报告编号 |
| session_id | TEXT | 会话标识 |
| question | TEXT | 问题 |
| plan | TEXT | 计划步骤（JSON 字符串） |
| code | TEXT | 生成代码 |
| output | TEXT | 结果数据（JSON 字符串） |
| conclusion | TEXT | 结论 |
| charts | TEXT | 图表配置（JSON 字符串） |
| created_at | TEXT | 时间 |

## 3. 数据访问层
- 统一通过 `db/session.py` 的 `get_connection()` 连接；
- 事务：各写操作 `commit()`；
- 查询：`get_analysis`、`list_analysis_by_session`、`query_audit`（分页+关键字）、`list_tables`；
- 写入：`save_analysis`、`write_audit`。

## 4. 画像缓存策略
- 上传时把 Schema 画像 `model_dump_json()` 存入 `tables.profile_json`；
- 分析和画像接口优先读取缓存，避免重复计算；
- 会话数据（`_sessions`）在内存中保存，用于追问，重启后不可用（符合课程演示场景）。

## 5. 备份与清理
- `.gitignore` 忽略 `data/*.db`，数据库为运行时产物不提交仓库；
- 演示用途无需持久化备份；生产可迁移 PostgreSQL（预留对接口适配）。

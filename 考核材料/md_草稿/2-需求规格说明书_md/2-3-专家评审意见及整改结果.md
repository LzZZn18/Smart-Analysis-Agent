# 专家评审意见及整改结果

> 项目：表格数据 + LLM 融合的企业智能分析 Agent
> 会议时间：2026-__-__ · 记录人：成员A

## 一、会议信息
- 参与人：指导教师、全体小组成员。
- 评审内容：需求规格说明书初稿、技术方案与接口设计。

## 二、专家/教师评审意见汇总

| 编号 | 意见 | 提出方 |
|:--:|:---|:---|
| R1 | 沙箱的安全边界需明确：禁网络、CPU/内存限额如何真正落地，不能只靠白名单 import | 教师 |
| R2 | "极简追问补全"缺少明确验收标准，如何证明补全正确、避免数据编造 | 教师 |
| R3 | 报告导出需嵌入真实图表图片，仅列"图表类型文字"意义有限，且需保证可溯源 | 教师 |
| R4 | 审计留痕要区分操作类型（提问/追问/导出），并支持分页检索 | 教师 |
| R5 | 前端已上传表格列表刷新会丢失，需持久化；多表应支持批量上传 | 其他组 |
| R6 | 评测集需量化正确率/一次通过率，作为验收硬指标 | 教师 |
| R7 | 表名字段与前端展示中文化应统一，命名需与评分规范一致 | 教师 |

# 接口设计说明书

> 项目：表格数据 + LLM 融合的企业智能分析 Agent
> 版本：v1.0 · 编写：成员B

## 1. 接口总览

| 接口 | 方法 | 说明 |
|:---|:---|:---|
| `/api/tables/upload` | POST | 上传表格，返回 table_id |
| `/api/tables` | GET | 列出已上传表格（刷新恢复列表） |
| `/api/tables/{id}/profile` | GET | 返回 Schema 画像（读缓存） |
| `/api/analysis/ask` | POST | 发起自然语言分析 |
| `/api/analysis/followup` | POST | 多轮追问 / 假设检验 |
| `/api/report/{id}/export?fmt=docx\|pdf` | GET | 导出报告（含图表图片） |
| `/api/admin/audit?page&size&keyword` | GET | 分页查询审计日志 |
| `/api/health` | GET | 健康检查 |

## 2. 通用约定
- 统一 JSON；错误返回 `{"detail": "..."}`。
- 中文 UTF-8；trace_id 关联审计。

## 3. 各接口详设

### 3.1 POST /api/tables/upload
请求：`multipart/form-data`，字段 `file`。
```json
{ "table_id": "5b307f610a36", "filename": "orders.csv", "row_count": 9, "col_count": 3 }
```

### 3.2 GET /api/tables
响应（数组）：
```json
[{ "table_id": "...", "filename": "orders.csv", "row_count": 9 }]
```

### 3.3 GET /api/tables/{id}/profile
响应：
```json
{
  "table_id": "...", "filename": "orders.csv",
  "columns": [{ "name": "region", "dtype": "str", "sample_values": ["华东"], "null_rate": 0, "cardinality": 3, "semantics": "" }]
}
```

### 3.4 POST /api/analysis/ask
请求：
```json
{ "question": "各区域销售额", "table_ids": ["..."], "session_id": "" }
```
响应（AnalysisResult）：
```json
{
  "question": "...", "plan": ["..."], "code": "...",
  "output": [{"region": "华东", "sales": 309000}],
  "conclusion": "...", "charts": [{"chart_type": "bar", "option": {...}}],
  "report_id": "...", "session_id": "..."
}
```

### 3.5 POST /api/analysis/followup
请求：
```json
{ "session_id": "...", "question": "一月呢？" }
```
内部先补全追问再走完整分析，返回与 ask 相同结构。

### 3.6 GET /api/report/{id}/export
查询参数 `fmt=docx|pdf`。返回文件字节流，`Content-Disposition` 用 RFC5987 `filename*` 处理中文文件名；报告中嵌入真实图表图片。

### 3.7 GET /api/admin/audit
查询参数 `page`、`size`、`keyword`。
```json
{ "total": 3, "page": 1, "size": 20,
  "items": [{ "trace_id": "...", "user": "anonymous", "action": "ask", "question": "...", "code": "...", "created_at": "..." }] }
```

### 3.8 错误码
| 场景 | HTTP |
|:---|:---|
| 未上传表格 | 400 |
| 会话不存在 | 400 |
| 报告不存在 | 404 |
| 不支持格式 | 400 |
| 未配置 Key | 500（明确提示） |

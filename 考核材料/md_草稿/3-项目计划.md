## 5. 风险管理表

| 风险 | 概率 | 影响 | 应对 |
|:---|:---|:---|:---|
| LLM 生成代码错误率高 | 中 | 高 | Schema 注入+反思+降噪 |
| API 不稳定/超时 | 中 | 中 | Ollama 兜底+重试+离线预案 |
| 沙箱被绕过 | 低 | 高 | 白名单+禁网+限额+逃逸测试 |
| 百万行性能不足 | 中 | 中 | DuckDB 列式+预聚合+采样 |
| 多表关联键推断错 | 中 | 中 | 值域重叠+LLM 二次确认 |
| 4周工期紧张 | 高 | 高 | P0→P1 滚动交付+每周评审 |

# 技术规范文档（Technical Specification）

> 项目：表格数据 + LLM 融合的企业智能分析 Agent
> 编写：成员B / 成员C · 版本 v1.0

## 1. 技术栈规范

| 层次 | 技术 | 版本（实测） | 位置 |
|:---|:---|:---|:---|
| 后端 | Python + FastAPI | Python 3.13 · FastAPI 0.141 | `backend/` |
| 表格引擎 | DuckDB / pandas / pyarrow | 1.5.5 / 3.0.5 / 25.0.1 | `services/schema_profiler.py` |
| 大模型 | DeepSeek API（httpx） | — | `services/llm.py` |
| 报告 | python-docx / reportlab / matplotlib | — | `services/reporter.py` |
| 前端 | React + Vite + TypeScript + ECharts | — | `frontend/` |
| 存储 | SQLite（内置） | — | `db/session.py` |
| 依赖管理 | uv（虚拟环境 .venv） | — | 根目录 |

## 2. 后端规范

- 应用入口 `app/main.py`，路由注册 tables/analysis/report/admin；
- 配置集中在 `core/config.py`，支持 `.env`（`python-dotenv`）覆盖：`LLM_PROVIDER`、`LLM_API_BASE`、`LLM_API_KEY`、`LLM_MODEL` 等；
- 数据模型用 Pydantic（`core/schemas.py`）；
- 业务层 `services/`：agent、llm、sandbox(+worker)、joiner、charting、reporter、schema_profiler；
- 数据层 `db/session.py`：建表 + 迁移 + CRUD + 审计分页。
- **代码规范**：全量中文注释；函数/类/变量/参数/接口调用均注释；`ruff` 风格兼容。

## 3. 前端规范
- React + TypeScript 严格模式；`App.tsx` 按 `?view=audit` 切换主界面/审计页；
- `index.css` 统一设计系统（配色/卡片/按钮/表格）；
- 后端调用经 `/api` 前缀 + Vite proxy 转发到 8000。

## 4. 环境与启动
```bash
# 后端
cd backend && uv pip install -r requirements.txt
uv run uvicorn app.main:app --reload --port 8000
# 前端
cd frontend && npm install && npm run dev   # http://localhost:5173
```

## 5. 关键实现要点
- 沙箱 worker 子进程 + 白名单 import + timeout 强杀；
- 报告用 matplotlib(`.Agg`) 自绘图表图片嵌 docx/pdf；
- 追问补全 `complete_followup` 结合上轮问题/结论/画像；
- 画像缓存与审计写入。

## 6. 依赖清单
见 `backend/requirements.txt`（fastapi、uvicorn、pydantic、httpx、python-docx、reportlab、duckdb、pandas、pyarrow、openpyxl、python-multipart、matplotlib）与 `frontend/package.json`（react、echarts、vite、ts）。

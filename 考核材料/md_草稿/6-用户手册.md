# 用户手册 / 操作手册

> 项目：表格数据 + LLM 融合的企业智能分析 Agent
> 编写：成员E · 版本 v1.0

## 1. 简介
本系统让你用**自然语言**对上传的表格做数据分析：会上传 Excel/CSV 即可分析，无需 SQL。

## 2. 快速开始
1. 启动后端与前端（详见《技术规范文档》）；
2. 打开浏览器 http://localhost:5173 ；
3. 点击"上传表格"选择 .csv/.xlsx（可多选）；
4. 在"用自然语言提问"输入问题，点"发起分析"；
5. 查看结果：图表、结论、可导出报告，可继续追问。

## 3. 功能使用

### 3.1 上传表格
- 支持一次选择多个文件（批量上传）；
- 已上传文件以标签形式展示，可 ✕ 移除；
- 刷新页面后已上传列表会自动恢复。

### 3.2 自然语言提问
示例："各区域销售额及占比""华东地区2月的销售额是多少"。

### 3.3 追问 / 假设检验
分析后，在"继续追问/假设检验"输入框提问，如"剔除华东区域会怎样""一月呢？"。系统会结合上一轮结果继续分析。

### 3.4 导出报告
点"导出 Word/PDF"，下载包含问题、结论、数据表、真实图表、代码的报告。

### 3.5 审计日志（管理员）
点页面右上角"审计日志"，在新窗口分页查看"谁/何时/问了什么/跑了什么代码"。

### 3.6 智能体决策过程
结果下方点"🔍 智能体决策过程"，可查看分析计划与生成代码（可复现）。

## 4. 常见问题
- 分析很慢？真实大模型需几秒，属于正常。
- 未出图表？概述型问题（如"几行几列"）无需图表。
- 报告打不开？确认后端已在运行。

## 5. 演示数据
`data/demo_data/`：`orders_demo.csv`（订单）、`regions_demo.csv`（负责人），可用于多表关联演示。
